10 · Firebase — Authentication & Cloud Firestore

Authentication (Google Sign-In) — authStateChanges điều hướng signed out → /sign-in, signed in → /classes. Sign-out xoá state cục bộ, set Analytics user ID = null, Crashlytics user ID = signed_out. Ca lỗi: hủy đăng nhập → "Sign-in cancelled" · mất mạng → "Network error" · email sai → ô viện đỏ (S19). Không crash, không treo loading. Bằng chứng: ảnh Console → Authentication → Users.

Cloud Firestore — đọc realtime bằng Stream, ghi bằng batch (import) hoặc transaction (duyệt/undo). firestore.rules khoá theo mentorUid, chặn sửa status/source sau khi tạo, và chỉ cho approve khi roster 5–6. Ca lỗi: permission-denied → PermissionDeniedError · unavailable → NetworkError · deadline-exceeded → TimeoutAppError — tất cả ra Failure kèm nút "Try again". Bằng chứng: firebase/firestore.rules + bộ test luật trên Rules emulator (firebase/test/firestore.rules.test.mjs).

11 · Firebase — Cloud Storage & Cloud Messaging

Cloud Storage — sinh PDF bằng package pdf từ cùng stream Firestore mà mentor đang xem (nên file phản ánh đúng màn hình) → upload reports/{uid}/{id}.pdf → hiện tiến độ + storage path + download URL (copy được). storage.rules: chỉ request.auth.uid == uid đọc/ghi thư mục của mình, chỉ nhận .pdf, ≤ 5 MiB, contentType = application/pdf. Không dùng allow read, write: if true. Ca lỗi: upload lỗi → thông báo + Crashlytics non-fatal; mất mạng → retry. Bằng chứng: ảnh Storage Console (danh sách file) + ảnh màn S6 hiện URL.

Cloud Messaging (FCM) — xin quyền thông báo Android 13+; token lưu ở users/{uid}/fcmTokens/{tokenId}; thông báo nhận được lưu vào trung tâm thông báo trong app; chạm thông báo điều hướng theo payload route — chỉ khi route nằm trong allow-list (chống deep-link tới màn ngoài phạm vi). Ca lỗi: người dùng từ chối quyền → app vẫn chạy, hiện thông báo rõ, các tính năng khác không bị chặn. Bằng chứng: ảnh nhận thông báo ở 3 trạng thái — mở / nền / đã đóng.

12 · Firebase — Remote Config, Analytics & Crashlytics

Remote Config — 2 tham số đổi hành vi nhìn thấy được:

Tham số Mặc định Ảnh hưởng nhìn thấy được
ai_matching_enabled true Ẩn/hiện nút "Match with AI" (S3/S4/S5)
max_proposals_shown 3 Số thẻ đề xuất ở S9

onConfigUpdated (realtime) → đổi giá trị trong Console áp dụng ngay, không build lại. Mất mạng → dùng giá trị mặc định trong app.

Analytics — 10 event, kế hoạch viết trước code, mỗi event có câu hỏi sản phẩm:

Event Tham số Câu hỏi
login / logout method Mentor quay lại mỗi tuần? Phiên dài bao lâu?
class_import row_count, available_count Mỗi lớp còn bao nhiêu SV lẻ?
view_item item_category, item_id Mentor xem gì trước khi duyệt?
ai_match_start / ai_match_result student_count, team_count, proposal_count, no_match, duration_ms Tỉ lệ ghép không ra kết quả?
proposal_approve / proposal_discard / member_change_blocked member_count, major_count, source, edited, reason Duyệt nhóm AI hay ghép tay? Có hay cố thêm người thứ 7?
report_export team_count, file_size_kb Sau khi duyệt, có lấy báo cáo không?

Không dữ liệu cá nhân: chỉ MSSV, classId, teamId, proposalId và số đếm. Tracking là best effort — lỗi Analytics không bao giờ làm hỏng luồng người dùng.

Crashlytics — fatal qua FlutterError.onError + PlatformDispatcher.onError; non-fatal từ đường lỗi thật: import file sai định dạng · AI timeout 30 s · upload PDF lỗi · transaction cập nhật roster lỗi. Gắn user ID + custom key role, class_id. Nút test crash ở khu demo S6.
